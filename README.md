# Food Waste Management System

This project is a Food Waste Management application that analyzes food waste data and provides meaningful insights through an interactive dashboard built using Streamlit. The project focuses on using SQL queries for data analysis while allowing users to manage and update the data directly within the application.
The system is designed to help understand food waste patterns, monitor important data, and support better decision-making through clear visualizations and analytics.
Project Overview
In this project, SQL queries are used to perform data analysis and extract insights from the dataset. The results are then displayed in a dashboard within the Streamlit application. Users can also interact with the system using CRUD operations, which allow them to add new data, update existing records, delete incorrect entries, and modify information as needed.

## Key Features

* SQL-based data analysis
* Interactive dashboard built in Streamlit
* CRUD operations (Create, Read, Update, Delete) for managing data
* Real-time reflection of data changes in the dashboard
* User-friendly interface for exploring insights

## Technologies Used

1. Python
2. SQL
3. Streamlit
4. Pandas
5. Data Visualization

## Project Objective
The main objective of this project is to demonstrate how data analysis, database operations, and interactive dashboards can be combined to build a practical data-driven application for managing and analyzing food waste data.
